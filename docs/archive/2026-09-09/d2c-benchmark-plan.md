# D2C Benchmark 实施计划（历史摘要）

> 日期：2026-09-09
> 状态：已执行，不再作为当前操作清单。

## 目标

提供与日常 D2C 隔离的固定 Benchmark，让用户在本地模型环境中一次生成四种页面，并排查看 Figma 原稿和真实页面。

## 已执行工作

1. 建立 Benchmark 静态检查和行为场景。
2. 提供 React + Ant Design + ECharts 的 PC 脚手架。
3. 提供 Vue 3 + Vant 的移动端脚手架。
4. 提供统一并排预览页、`latest` 重置和启动脚本。
5. 实现四场景一次执行、场景级失败隔离和人工预览边界。

## 固定边界

- Benchmark 不修改业务项目，也不复用日常 `D2C.md`。
- 场景使用本地模拟数据，不猜测真实 API。
- 不评分、不排名、不输出通过或失败结论。
- 全局前置条件失败时整轮停止；单节点失败时保留失败页签并继续其他场景。
- 每轮重建 `latest`，不维护历史运行目录。

当前行为以 `skills/d2c-benchmark/SKILL.md` 为准。完整任务步骤可通过 Git 历史查看。
