  1. 创建 Plugin 目录结构

  design-to-code-plugin/
  ├── .claude-plugin/
  │   └── plugin.json            ← 必需：插件清单
  ├── skills/                    ← 原 .claude/skills/ 内容迁移到这里
  │   ├── d2c/SKILL.md
  │   ├── d2c-extract/SKILL.md
  │   ├── d2c-generate/SKILL.md
  │   ├── d2c-validate/SKILL.md
  │   ├── d2c-verify/SKILL.md
  │   └── d2c-merge/SKILL.md
  ├── .mcp.json                  ← MCP 服务器配置
  ├── settings.json              ← 默认权限配置
  ├── templates/                 ← 模板文件
  │   └── vite-preview/...
  ├── context/                   ← 上下文模板
  └── scripts/                   ← 辅助脚本

  2. 创建 plugin.json 清单

  {
    "name": "d2c",
    "description": "Design-to-Code: Convert Figma designs to Vue 3 + TypeScript with visual verification",
    "version": "1.0.0",
    "author": { "name": "your-name" },
    "repository": "https://github.com/your-name/design-to-code-plugin",
    "license": "MIT"
  }

  3. 创建 Marketplace（用于分发）

  在你的 GitHub 仓库根目录放一个 marketplace.json：

  {
    "name": "d2c-marketplace",
    "owner": { "name": "your-name" },
    "plugins": [
      {
        "name": "d2c",
        "source": "./",
        "description": "Figma Design to Vue 3 Code",
        "version": "1.0.0"
      }
    ]
  }

  用户安装方式

  用户在 Claude Code 中执行：

  # 添加你的 marketplace
  /plugin marketplace add your-name/design-to-code-plugin

  # 安装插件
  /plugin install d2c@d2c-marketplace

  # 启用
  /plugin enable d2c@d2c-marketplace

  安装后用户即可在任何项目中使用 /d2c <figma-url>。

  也可通过 npm 分发

  # 发布
  npm publish

  # 用户安装
  /plugin install d2c@npm

  npm 方式需要在 marketplace 的 plugin source 中配置：

  {
    "name": "d2c",
    "source": { "source": "npm", "package": "@your-name/d2c-plugin", "version": "^1.0.0" }
  }

  ---
  需要注意的问题

  1. MCP 配置：Plugin 中的 .mcp.json 会随插件加载，但 Figma API Key 需要用户自己配置（可通过环境变量 FIGMA_API_KEY 解决）
  2. context/ 文件：这些是用户自定义的，Plugin 安装后需要引导用户在自己项目中创建
  3. templates/ 路径：Plugin 安装后路径会变化（在 ~/.claude/plugins/cache/ 下），脚本和 skill 中的相对路径需要适配
